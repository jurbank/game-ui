# @gameui/react

## 0.1.0

### Minor Changes

- Initial release.

  - `@gameui/themes`: semantic `--game-*` tokens, the Arcade, Tactical, and Playful themes, base styles, and a Tailwind CSS v4 mapping.
  - `@gameui/react`: Button, Panel, Modal, ProgressBar, Timer, PlayerList, and Scoreboard, precompiled into a layered stylesheet.
  - `@gameui/world-ui`: type-only contracts for FloatingLabel, Nameplate, and HealthBar, drawn by game-owned renderers.
  - `@gameui/core`: token names and helpers shared by themes, components, and native renderers.

### Patch Changes

- Updated dependencies
  - @gameui/core@0.1.0
  - @gameui/themes@0.1.0
