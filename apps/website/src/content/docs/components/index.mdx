## Available

| Component                                | Package            | Use it for                                   |
| ---------------------------------------- | ------------------ | -------------------------------------------- |
| [Button](/components/button/)            | `@gameui/ui/react` | Actions such as ready, confirm, and leave    |
| [Panel](/components/panel/)              | `@gameui/ui/react` | Grouping HUD sections, menus, and summaries  |
| [Modal](/components/modal/)              | `@gameui/ui/react` | Pause menus and confirmations                |
| [ProgressBar](/components/progress-bar/) | `@gameui/ui/react` | Health, shields, experience, and loading     |
| [Timer](/components/timer/)              | `@gameui/ui/react` | Match, round, and cooldown clocks            |
| [PlayerList](/components/player-list/)   | `@gameui/ui/react` | Lobby rosters, ready checks, and party lists |
| [Scoreboard](/components/scoreboard/)    | `@gameui/ui/react` | Match results and live standings             |

## World UI concepts

These are TypeScript contracts in `@gameui/ui`, drawn by your game's renderer rather than shipped as React components.

| Concept                                    | Package      | Use it for                                    |
| ------------------------------------------ | ------------ | --------------------------------------------- |
| [FloatingLabel](/world-ui/floating-label/) | `@gameui/ui` | Place names and short-lived world feedback    |
| [Nameplate](/world-ui/nameplate/)          | `@gameui/ui` | Names, status, and selection above characters |
| [HealthBar](/world-ui/health-bar/)         | `@gameui/ui` | Health above characters and objects           |

See [World UI and state](/getting-started/world-ui-and-state/) for implementing them.

## Planned

Toast, Lobby, HUDLayout, DamageNumber, InteractionPrompt, and ObjectiveMarker are candidates, extracted only when real games show a reusable API. Until then, compose the components above.
