## Available

| Component                                | Package          | Use it for                                   |
| ---------------------------------------- | ---------------- | -------------------------------------------- |
| [Button](/components/button/)            | `@game-ui/react` | Actions such as ready, confirm, and leave    |
| [Panel](/components/panel/)              | `@game-ui/react` | Grouping HUD sections, menus, and summaries  |
| [Modal](/components/modal/)              | `@game-ui/react` | Pause menus and confirmations                |
| [ProgressBar](/components/progress-bar/) | `@game-ui/react` | Health, shields, experience, and loading     |
| [Timer](/components/timer/)              | `@game-ui/react` | Match, round, and cooldown clocks            |
| [PlayerList](/components/player-list/)   | `@game-ui/react` | Lobby rosters, ready checks, and party lists |
| [Scoreboard](/components/scoreboard/)    | `@game-ui/react` | Match results and live standings             |

## Planned

These components are part of the initial milestone but do not exist yet: FloatingLabel, Nameplate, and HealthBar for [world UI](/world-ui/).

Until a planned component ships, compose available components and keep any game-specific UI in your game.
